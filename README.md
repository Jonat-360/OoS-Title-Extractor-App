# OoS Title Extractor

Turns the Shore Pres weekly order of service (`.docx`) into the plain-text
title list for the OBS title bar on the Zoom stream.

**Open or install the app: https://jonat-360.github.io/OoS-Title-Extractor-App/**

In Chrome, Edge, Helium or another Chromium-based browser, choose **Install**
(the icon at the right of the address bar, or the browser menu) to get it as
an app with its own window and icon. Once installed it works offline and
updates itself.

Your documents never leave your computer: the app reads them inside your
browser, and nothing is uploaded.

This repository only holds the published app. Its source code and tests are
kept in a separate private repository, and the files here are generated
from it, so changes made here directly will be overwritten.
